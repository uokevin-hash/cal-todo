## 번호 정책

- `WF-n`은 한 번 붙이면 바꾸거나 다시 쓰지 않는다. 새 항목은 마지막 번호 다음을 쓰고, 없어진 항목은 `(폐기, vX.Y)`로 남긴다. WF-01 ~ WF-09는 같은 번호의 SCR에 대응하고, 여러 화면이 함께 쓰는 모달은 WF-10부터 붙였다. WF-12부터는 나중에 생긴 구역·화면이다(WF-12는 SCR-03 안의 그룹 채팅 구역, WF-13은 SCR-10).

## 2. 공통 레이아웃

### 2.1 브레이크포인트 (NFR-12)

| 구분 | 폭 | 레이아웃 |
|------|----|----------|
| 모바일 | 360 ~ 767px | 1열. 상단 바 + 햄버거 메뉴. 표는 카드 목록으로 바꾼다. 입력 칸은 라벨 위, 칸 아래 배치. 모달은 하단 시트(WF-05, WF-10) 또는 전체 화면(회원 편집 패널)으로 바꾼다. 좌우 여백 16px |
| 데스크톱 | 768px 이상 | 상단 가로 메뉴. 본문은 최대 폭 1080px, 가운데 정렬, 좌우 여백 24px. 표 사용, 입력 칸은 라벨 왼쪽 |

- 768px(태블릿 세로)부터 데스크톱 레이아웃이다. SCR-08의 가장 넓은 표(5열)도 768px에 들어간다.
- 360px 미만은 대상이 아니다. 줄어들더라도 가로 스크롤이 생기는 것까지만 허용한다.
- 와이어프레임 폭: 데스크톱 78자, 모바일 36자(360px 가정). 한글 한 글자는 두 칸으로 셌다.

### 2.2 앱 셸

로그인 화면(WF-01)과 회원가입(WF-02)에는 셸이 없다. 나머지 화면은 아래 셸 안에 들어가며, 4장의 데스크톱 WF는 셸을 빼고 본문만 그린다. 모바일 WF는 상단 바까지 그린다.

데스크톱 · 회원 (78자 폭에 다 들어가지 않아 오른쪽 묶음을 둘째 줄에 그렸다. 실제로는 한 줄이다)

```
┌────────────────────────────────────────────────────────────────────────────┐
│ Badminatics  캘린더  참석 현황  내 정보                                    │
│              (minsu@example.com:로그인중:사용자)  [한국어 ▼]  [ 로그아웃 ] │
├────────────────────────────────────────────────────────────────────────────┤
│                                                                            │
│                     본문 (최대 폭 1080px, 가운데 정렬)                     │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘
```

데스크톱 · 관리자 (`회원 관리`·`그룹 관리`·`채팅 보관함`이 더 붙는다, R-8)

```
┌────────────────────────────────────────────────────────────────────────────┐
│ Badminatics  캘린더  참석 현황  내 정보  회원 관리  그룹 관리  채팅 보관함 │
│                   (park@club.kr:로그인중:관리자)  [한국어 ▼]  [ 로그아웃 ] │
└────────────────────────────────────────────────────────────────────────────┘
```

- 오른쪽 묶음은 로그인 정보 `(이메일:로그인중:관리자|사용자)`(길면 말줄임), 언어 선택(`한국어`·`English`·`中文`, SCR 공통 요소), [로그아웃] 순서다.
- 지금 보고 있는 메뉴는 굵은 글씨 + 밑줄로 표시한다. 상단 바는 스크롤해도 위에 고정한다.

모바일 · 상단 바와 메뉴 서랍

```
┌──────────────────────────────────┐
│ ≡  캘린더             [한국어 ▼] │
├──────────────────────────────────┤
│                                  │
│               본문               │
│                                  │
└──────────────────────────────────┘
```

```
┌──────────────────────────────────┐
│ 박관리 (관리자)                ✕ │
├──────────────────────────────────┤
│ ▶ 캘린더                         │
│   참석 현황                      │
│   내 정보                        │
├──────────────────────────────────┤
│   회원 관리           (관리자만) │
│   그룹 관리           (관리자만) │
│   채팅 보관함         (관리자만) │
├──────────────────────────────────┤
│   로그아웃                       │
└──────────────────────────────────┘
```

- **모바일 메뉴는 햄버거(≡) + 왼쪽 서랍**으로 한다. 이유: 관리자 메뉴는 6개 + 로그아웃이라 360px 하단 탭에 다 들어가지 않고, 역할에 따라 탭 수가 달라지지 않게 하기 위해서다.
- 서랍은 왼쪽에서 폭 280px로 열리고 나머지 화면은 어둡게 덮는다. 바깥을 누르거나 ✕, 메뉴 항목을 누르면 닫힌다. 서랍에는 언어 선택이 없다.
- 모바일 상단 바는 ≡ + 지금 화면 이름 + 오른쪽 언어 선택이다. 로고·로그인 정보·[로그아웃]은 숨기고, 로그아웃은 서랍에서 한다.
- WF-04는 ≡ 대신 `←`(뒤로, 들어온 기록이 없으면 WF-03으로)를 두고, 화면 이름 자리에 `10월 3일 (토)`처럼 날짜를 쓴다. 회원 편집 패널은 전체 화면 머리에 `←`를 둔다.

### 2.3 표기

| 표기 | 뜻 |
|------|----|
| `[ 저장 ]` | 버튼 |
| `{ 참석 }` | 비활성 버튼(흐리게). 눌러도 동작하지 않지만 이유를 토스트로 알린다(SCR-04) |
| `[______]`, `[김민수__]` | 입력 칸(빈 칸 / 값이 있는 칸) |
| `[전체 ▼]`, `[1974-11-14 ▼]` | 선택 상자 / 날짜 선택 |
| `( )` `(●)`, `[ ]` `[✔]` | 라디오 / 체크 상자. 라디오로 그린 정원·역할 고르기는 화면에서 세그먼트 선택으로 그린다(스타일 가이드 5.3) |
| `[전체\|참석가능\|참석완료]` | 세그먼트 선택(붙은 버튼 중 고른 하나만 채움) |
| `(잠김)` | 보이지만 바꿀 수 없는 칸 |
| `<참석가능 (3/4)>` | 상태 배지 |
| `! 문구` | 칸 아래 오류 문구(빨간 글씨) |
| `░` | 모달 뒤 어둡게 덮인 화면 |

### 2.4 공통 컴포넌트

| 컴포넌트 | 모양 | 쓰는 곳 |
|----------|------|---------|
| 상태 배지 | 둥근 테두리 글자 `<참석가능 (n/정원)>`(초록 계열) · `<참석완료 (n/정원)>`(회색 채움) · `<참석불가 (n/정원)>`(회색 채움, 지난 날짜에서 정원이 차지 않은 그룹). 문구는 SCR 공통 요소, 계산은 R-5·R-6 | WF-04, WF-06 |

| 확인 창 | WF-11 | WF-04, WF-08, WF-09, WF-12, WF-13 |
| 빈 상태 | 목록 자리 가운데 회색 글씨 한두 줄. 다음 동작 버튼은 두지 않는다 | WF-04, WF-06, WF-08, WF-09, WF-12, WF-13 |

| WF-09 | [편집] / [삭제] | WF-10 / WF-11 |

| 모든 화면 | 401 `UNAUTHENTICATED`(D-4) | WF-01 + "다시 로그인해 주세요" |

- 칸에는 날짜 숫자(내가 참석한 날은 바로 옆에 ✔)와 그날의 그룹을 `그룹명(인원)` 한 줄씩 넣는다. 칸 폭을 넘으면 말줄임(…)하고, 칸 높이를 넘는 그룹은 잘린다. 칸 높이는 모바일 64px(그룹 약 두 줄), 데스크톱 96px(약 세 줄)다(NFR-12). 칸 전체가 눌리는 영역이며, 모바일 한 칸 폭은 약 48px다.

| 변형 | 배치 |
|------|------|
| 관리자 전용 [편집]·[삭제] (D-7) | 데스크톱·모바일 모두 카드 마지막 줄 왼쪽에 작은 버튼 `[편집] [삭제]`, 오른쪽에 동작 버튼([참석]·[참석 취소]·`(마감)`). 회원에게는 자리째 없다. 날짜와 관계없이 보인다 |
| 내가 참석한 그룹 | 그룹명 옆 `✔`, 카드 배경을 옅은 보라로 칠하고 왼쪽에 보라 선을 그은 뒤 [참석 취소]를 보인다 |
| 정원 찬 그룹 | 버튼 자리에 회색 `(마감)` 글자(R-3) |
| 비활성 버튼 | 지난 날짜(R-6)이거나, 그날 이미 참석(R-4)했거나, `기본` 그룹이 정원 참(R-3)이면 `{ }`로 흐리게. 누르면 토스트로 이유를 알린다(SCR-04) |
| 지난 날짜 (R-6) | [+ 그룹 만들기]·[그룹 없이 참석]·[참석]이 `{ }`로 흐려진다. [참석 취소]는 그대로 쓸 수 있다. 정원이 차지 않은 그룹의 배지는 `<참석불가 (n/정원)>` |
| 마지막 참석자의 [참석 취소] (R-16) | 위 `연습B`처럼 참석자가 나 한 명이면, [참석 취소]를 눌렀을 때 WF-11 확인 창([삭제]/[남기기])이 먼저 뜬다 |
| 탈퇴 회원 | 참석자 이름 자리에 비관리자는 `탈퇴 회원`, 관리자는 `최민호(탈퇴)`(R-9). 탈퇴 회원의 참석은 지난 날짜에만 남으므로(R-9) 위 예시(10/3, 오늘 이후)에는 없다 |

- 데스크톱 필터는 늘 펼쳐 둔 2열(기간·그룹명 / 참석자 이름·상태 / 정원·[조회])이다. 화면 제목 `참석 현황`은 데스크톱에서만 본문에 보인다.
- 필터 요약 줄을 누르면 펼쳐지고, [조회]를 누르면 접히며 결과 카드가 보인다. 요약 줄에는 기간과 입력한 그룹명·참석자 이름만 넣는다(상태·정원은 넣지 않는다).
- 기간 오류(93일 초과, 종료일이 시작일보다 앞섬)는 기간 칸 아래 칸 오류로 보인다(SCR-06).
- 지난 날짜에서 정원이 차지 않은 그룹은 배지가 `<참석불가 (n/정원)>`로 보인다(2.4).
- 행(카드) 전체가 눌리는 영역이다 → 그 날짜의 WF-04. 참석자가 한 줄을 넘으면 줄바꿈한다(최대 4명).
- 관리자에게는 `탈퇴 회원` 자리가 `최민호(탈퇴)`로 보인다(R-9). 결과가 없으면 빈 상태 문구(2.4).

| WF-08 [삭제] | 회원 삭제 | SCR-08 삭제 문구 | [삭제] [취소] |
| WF-04 [참석 취소] (마지막 참석자) | 참석 취소 | SCR-04 마지막 참석자 문구(그룹명 포함) | [삭제] [남기기] |
| WF-13 [삭제] | 보관된 채팅 삭제 | SCR-10 삭제 문구(날짜·그룹명, 메시지 수 n 포함) | [삭제] [취소] |
| WF-12, WF-13 이미지 오른쪽 버튼 | 이미지 내려받기 | "이미지를 내려받을까요? (chat-{메시지 번호}.{확장자})" | [내려받기] [취소] |

- 모바일에서도 확인 창은 하단 시트가 아니라 화면 가운데 작은 창(폭 = 화면 − 32px, 최대 400px)이다. 버튼은 오른쪽에 모으고, 앞 버튼([삭제])은 빨간 채움 버튼이다. 이미지 내려받기만 [내려받기]가 주 버튼이다. 바깥을 눌러도 닫히지 않고 뒤 버튼([취소]·[남기기])으로만 닫는다. [남기기]는 닫으면서 참석만 취소한다(SCR-04).

### WF-12. 그룹 채팅 (SCR-03 그룹 채팅 구역)

데스크톱 · 이지은이 보는 화면 (캘린더 아래, 첫 탭을 고른 상태)

```
┌────────────────────────────────────────────────────────────────────────────┐
│ … WF-03 캘린더와 범례                                                      │
├────────────────────────────────────────────────────────────────────────────┤
│ 그룹 채팅                                                                  │
│ [10/3(토) 토요복식]  [10/10(토) 연습A]                                     │
│ ┌────────────────────────────────────────────────────────────────────────┐ │
│ │ 정하늘 · 10. 2. 오후 08:10                                             │ │
│ │ ┌──────────────────────────────┐                                       │ │
│ │ │ 토요일 7시에 코트 A에서 봐요 │                                       │ │
│ │ └──────────────────────────────┘                                       │ │
│ │ 서준호 · 10. 2. 오후 08:12                                             │ │
│ │ ┌──────────┐                                                           │ │
│ │ │ ▣ 이미지 │                                                           │ │
│ │ └──────────┘                                                           │ │
│ │                                             이지은 · 10. 2. 오후 08:15 │ │
│ │                                                          ┌───────────┐ │ │
│ │                                                          │ 네 갈게요 │ │ │
│ │                                                          └───────────┘ │ │
│ ├────────────────────────────────────────────────────────────────────────┤ │
│ │ [메시지를 입력하거나 이미지를 붙여넣으세요________________]   [ 전송 ] │ │

└────────────────────────────────────────────────────────────────────────────┘
```

모바일 · 이미지를 붙여넣은 상태

```
┌──────────────────────────────────┐
│ ≡  캘린더             [한국어 ▼] │
├──────────────────────────────────┤
│ … WF-03 캘린더와 범례            │
├──────────────────────────────────┤
│ 그룹 채팅                        │
│ [10/3(토) 토요복식]              │
│ [10/10(토) 연습A]                │
│ ┌──────────────────────────────┐ │
│ │ 정하늘 · 10. 2. 오후 08:10   │ │
│ │ ┌───────────────────┐        │ │
│ │ │ 토요일 7시 코트 A │        │ │
│ │ └───────────────────┘        │ │
│ │   이지은 · 10. 2. 오후 08:15 │ │
│ │                ┌───────────┐ │ │
│ │                │ 네 갈게요 │ │ │
│ │                └───────────┘ │ │
│ ├──────────────────────────────┤ │
│ │ ┌──────┐                     │ │
│ │ │ ▣    │ ✕                   │ │
│ │ └──────┘ ← 붙여넣은 이미지   │ │
│ │ [메시지를 입력…______][전송] │ │
│ └──────────────────────────────┘ │
└──────────────────────────────────┘
```

- 탭은 보고 있는 달에 내가 참석한 그룹마다 하나이고, 모바일에서는 줄바꿈된다. 고른 탭은 주 버튼 색이다(처음엔 첫 탭).
- 메시지 목록은 높이가 정해진 상자 안에서 스크롤된다. 메시지 위에 `이름 · 시각`, 내 메시지(위 이지은)는 오른쪽에 옅은 보라 말풍선, 다른 사람 메시지는 왼쪽에 회색 말풍선이다. `▣`는 받은 이미지다.
- 붙여넣은 이미지는 입력 줄 위에 미리보기와 ✕로 보이고, [전송]을 누르면 보낸다. 파일 선택 버튼은 없다.
- 동작·문구(복사, 이미지 형식, 크게 보기, 내려받기, 빈 상태)는 SCR-03 그룹 채팅 구역. 내려받기 확인은 WF-11.
