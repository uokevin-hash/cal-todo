# cal-todo 와이어프레임

> 근거: [1-definition.md](1-definition.md) **v0.14**, [2-user-scenarios.md](2-user-scenarios.md) **v0.17**, [2-PRD.md](2-PRD.md) **v0.11**, [3-screen-design.md](3-screen-design.md) **v0.15**. `WF-n`은 이 문서의 와이어프레임, `SCR-n`은 화면 설계서, `R-n`은 정의서의 비즈니스 규칙, `S-n`은 유저 시나리오, `FR-n`·`NFR-n`·`D-n`은 PRD 번호다. 이 문서는 시각 배치만 다룬다. 요소의 동작·검증·문구는 다시 적지 않고 `SCR-n`·`R-n`으로 참조한다.

## 번호 정책

- `WF-n`은 한 번 붙이면 바꾸거나 다시 쓰지 않는다. 새 항목은 마지막 번호 다음을 쓰고, 없어진 항목은 `(폐기, vX.Y)`로 남긴다. WF-01 ~ WF-09는 같은 번호의 SCR에 대응하고, 여러 화면이 함께 쓰는 모달은 WF-10부터 붙였다.

## 2. 공통 레이아웃

### 2.1 브레이크포인트 (NFR-12)

| 구분 | 폭 | 레이아웃 |
|------|----|----------|
| 모바일 | 360 ~ 767px | 1열. 상단 바 + 햄버거 메뉴. 표는 카드 목록으로 바꾼다. 입력 칸은 라벨 위, 칸 아래 배치. 모달은 하단 시트(WF-05, WF-10) 또는 전체 화면(회원 편집 패널)으로 바꾼다. 좌우 여백 16px |
| 데스크톱 | 768px 이상 | 상단 가로 메뉴. 본문은 최대 폭 1080px, 가운데 정렬, 좌우 여백 24px. 표 사용, 입력 칸은 라벨 왼쪽 |

- 768px(태블릿 세로)부터 데스크톱 레이아웃이다. SCR-08의 가장 넓은 표(5열)도 768px에 들어간다.
- 360px 미만은 대상이 아니다. 줄어들더라도 가로 스크롤이 생기는 것까지만 허용한다.
- 와이어프레임 폭: 데스크톱 78자, 모바일 36자(360px 가정). 한글 한 글자는 두 칸으로 셌다.

### 2.2 앱 셸

로그인 화면(WF-01)과 회원가입(WF-02)에는 셸이 없다. 나머지 화면은 아래 셸 안에 들어가며, 4장의 데스크톱 WF는 셸을 빼고 본문만 그린다. 모바일 WF는 상단 바까지 그린다.

데스크톱 · 회원

```
┌────────────────────────────────────────────────────────────────────────────┐
│ cal-todo  캘린더  참석 현황  내 정보                          [ 로그아웃 ] │
├────────────────────────────────────────────────────────────────────────────┤
│                                                                            │
│                     본문 (최대 폭 1080px, 가운데 정렬)                     │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘
```

데스크톱 · 관리자 (`회원 관리`·`그룹 관리`가 더 붙는다, R-8)

```
┌────────────────────────────────────────────────────────────────────────────┐
│ cal-todo  캘린더  참석 현황  내 정보  회원 관리  그룹 관리    [ 로그아웃 ] │
└────────────────────────────────────────────────────────────────────────────┘
```

- `그룹 관리`는 P1(FR-17)이라 P0 빌드에서는 데스크톱 메뉴와 모바일 서랍 모두에서 숨긴다(SCR 공통 요소, WF-09).
- 지금 보고 있는 메뉴는 굵은 글씨 + 밑줄로 표시한다. 상단 바는 스크롤해도 위에 고정한다.

모바일 · 상단 바와 메뉴 서랍

```
┌──────────────────────────────────┐
│ ≡  캘린더                        │
├──────────────────────────────────┤
│                                  │
│               본문               │
│                                  │
└──────────────────────────────────┘
```

```
┌──────────────────────────────────┐
│ 박관리 (관리자)                ✕ │
├──────────────────────────────────┤
│ ▶ 캘린더                         │
│   참석 현황                      │
│   내 정보                        │
├──────────────────────────────────┤
│   회원 관리            (관리자만)│
│   그룹 관리            (관리자만)│
├──────────────────────────────────┤
│   로그아웃                       │
└──────────────────────────────────┘
```

- **모바일 메뉴는 햄버거(≡) + 왼쪽 서랍**으로 한다. 이유: 관리자 메뉴는 5개 + 로그아웃이라 360px 하단 탭에 다 들어가지 않고, 역할에 따라 탭 수가 달라지지 않게 하기 위해서다.
- 서랍은 왼쪽에서 폭 280px로 열리고 나머지 화면은 어둡게 덮는다. 바깥을 누르거나 ✕, 메뉴 항목을 누르면 닫힌다.
- 상단 바 가운데 글자는 지금 화면 이름이다. WF-04와 회원 편집 패널은 ≡ 대신 `←`(뒤로)를 둔다.

### 2.3 표기

| 표기 | 뜻 |
|------|----|
| `[ 저장 ]` | 버튼 |
| `{ 참석 }` | 비활성 버튼(흐리게). 눌러도 동작하지 않지만 이유를 토스트로 알린다(SCR-04) |
| `[______]`, `[김민수__]` | 입력 칸(빈 칸 / 값이 있는 칸) |
| `[전체 ▼]`, `[1974-11-14 ▼]` | 선택 상자 / 날짜 선택 |
| `( )` `(●)`, `[ ]` `[✔]` | 라디오 / 체크 상자 |
| `(잠김)` | 보이지만 바꿀 수 없는 칸 |
| `<참석가능 (3/4)>` | 상태 배지 |
| `! 문구` | 칸 아래 오류 문구(빨간 글씨) |
| `░` | 모달 뒤 어둡게 덮인 화면 |

### 2.4 공통 컴포넌트

| 컴포넌트 | 모양 | 쓰는 곳 |
|----------|------|---------|
| 상태 배지 | 둥근 테두리 글자 `<참석가능 (n/정원)>`(초록 계열) · `<참석완료 (n/정원)>`(회색 채움). 문구는 SCR 공통 요소, 계산은 R-5 | WF-04, WF-06 |
| 버튼 | 주 버튼(채움, 예: [가입] [만들기] [저장])이 왼쪽, 보조 버튼(테두리, [취소])이 오른쪽. 순서는 SCR 배치를 따른다. 제출 중에는 버튼을 `{ 저장 중… }`처럼 비활성으로 바꿔 두 번 눌리지 않게 한다 | 전체 |
| 칸 오류 | 해당 입력 칸 바로 아래 빨간 글씨 한 줄 `! 문구`. 문구는 각 SCR | WF-01, 02, 05, 06, 07, 08, 10 |
| 토스트 | 화면 하단 가운데에 뜨는 어두운 상자, 3초 뒤 사라짐. 모바일은 좌우 16px 여백의 전체 폭. 업무 규칙 거부(D-4의 409: `CAPACITY_FULL`, `ALREADY_ATTENDING` 등)와 SCR-07의 "다른 기기에서는 로그아웃됩니다"에 쓴다 | WF-04, WF-05, WF-07 |
| 확인 창 | WF-11 | WF-04, WF-08, WF-09 |
| 빈 상태 | 목록 자리 가운데 회색 글씨 한두 줄 + 할 수 있는 다음 버튼 | WF-04, WF-06, WF-09 |
| 로딩 | 목록 조회 중에는 목록 자리에 회색 줄 3개(`░░░░`). 앱 시작 시 로그인 복원(PRD 6.1 흐름 6) 중에는 화면 가운데 `cal-todo` 로고만 보여 주고, 결과가 나오기 전에 WF-01을 잠깐 보여 주지 않는다. 로그인 연장은 표시하지 않는다(SCR 공통) | 전체 |

토스트 (예: 정원이 찬 그룹에 참석, R-3)

```
┌──────────────────────────────┐
│     정원이 가득 찼습니다     │
└──────────────────────────────┘
```

빈 상태 문구(새로 정함): WF-04 "이 날짜에는 아직 그룹이 없습니다", WF-06 "조건에 맞는 참석 기록이 없습니다", WF-09 "이 기간에 그룹이 없습니다".

## 4. 화면별 와이어프레임

### WF-01. 로그인 (SCR-01)

데스크톱 (강제 로그아웃 뒤 상태)

```

│                                                                            │
│             ┌────────────────────────────────────────────────┐             │
│             │                    cal-todo                    │             │
│             ├────────────────────────────────────────────────┤             │
│             │ ! 다시 로그인해 주세요                         │             │

│             │ 이메일    [__________________________________] │             │
│             │ 비밀번호  [__________________________________] │             │
│             │                                                │             │
│             │ [                   로그인                   ] │             │
│             │            계정이 없나요? 가입하기             │             │

│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘
```

모바일 (로그인 실패 상태)

```
┌──────────────────────────────────┐
│                                  │
│             cal-todo             │
│                                  │
│ 이메일                           │
│ [______________________________] │
│ 비밀번호                         │
│ [______________________________] │
│ ! 이메일 또는 비밀번호가         │
│   올바르지 않습니다              │
│                                  │
```

- `! 다시 로그인해 주세요` 안내는 강제 로그아웃(D-4 `UNAUTHENTICATED`, S-15)으로 들어왔을 때만 카드 맨 위에 노란 띠로 보인다. 직접 로그아웃하거나 처음 들어왔을 때는 없다.
- 로그인 실패 문구(SCR-01)는 [로그인] 버튼 바로 위에 보인다.

| 검색 (P1, FR-19) | P0 빌드에서는 검색 칸과 [검색] 버튼을 자리째 뺀다 |
