## 1. 원칙

| ID | 원칙 |
|----|------|
| SG-1 | **평평하고 선으로 나눈다.** 그림자·그라데이션 없이 흰 바탕 + 옅은 회색 선(1px)으로 영역을 나눈다. 강조는 색 하나(보라)로만 한다 |

| SG-4 | **참고 이미지의 브랜드 요소는 쓰지 않는다.** 로고, 서비스 이름, 브랜드 색(녹색 로고 등)은 가져오지 않는다. 로고 자리는 글자 `Badminatics`다(WF 2.2) |

## 3. 글자

| 토큰 | 크기 / 줄 높이 | 굵기 | 쓰는 곳 |
|------|---------------|------|---------|
| `--font-title` | 18px / 26px | 700 | 화면 제목, 캘린더 월 제목 `2026년 10월` |
| `--font-heading` | 15px / 22px | 700 | 구역 제목, 모달 제목, 날짜 상세의 그룹 이름 |
| `--font-body` | 14px / 20px | 400 | 본문, 입력 칸, 버튼, 메뉴 |
| `--font-small` | 12px / 18px | 400 | 요일, 캘린더 날짜 숫자, 칸 오류, 배지, 설명 |

- 위 토큰 이름은 문서용이다. CSS 변수로는 만들지 않았고, 각 규칙에 `18px`/`26px`, `15px`/`22px`, `12px`/`18px`을 직접 적는다(본문은 `body`의 `14px/20px`). 작은 버튼(5.2)만 표 밖 크기 13px를 쓴다.
- 글꼴: `-apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", "Malgun Gothic", "맑은 고딕", sans-serif`. 웹 폰트는 내려받지 않는다.
- 참고 이미지는 본문이 12px이지만, 360px 모바일에서 읽고 누르기 쉽도록 본문을 14px로 올렸다. 캘린더 칸 안 글자는 이미지처럼 12px로 둔다.
- 숫자(날짜, `3/4` 인원)는 `font-variant-numeric: tabular-nums`로 폭을 맞춘다.

## 5. 컴포넌트

### 5.1 앱 셸 (WF 2.2)

- **상단 바**: 흰 바탕, 높이 48px, 아래 선 `--color-line-soft`, 스크롤해도 위에 고정. 데스크톱은 왼쪽 `Badminatics`(15px 700, `--color-text-strong`), 그 오른쪽에 메뉴, 맨 오른쪽에 로그인 정보 `(이메일:로그인중:관리자|사용자)`(12px `--color-text-sub`, 최대 40vw에서 말줄임), 언어 선택(5.12), [로그아웃](보조 버튼). 모바일은 ≡(날짜 상세는 ←, 테두리 없는 아이콘 버튼 18px) + 화면 이름(15px 700 `--color-text-strong`) + 오른쪽 언어 선택만 두고 로고·로그인 정보·[로그아웃]은 숨긴다.
- **메뉴 항목**: 14px `--color-text`. 지금 화면은 700 + `--color-primary` 글자 + 아래 2px `--color-primary` 밑줄(WF 2.2의 "굵은 글씨 + 밑줄").
- **모바일 서랍**: 폭 280px 흰 바탕, 뒤는 `--color-overlay`. 항목 높이 44px, 지금 화면 항목은 `--color-primary-weak` 배경 + `--color-primary` 글자. 구역 사이 선 `--color-line-soft`. 맨 위 사용자 이름은 `--font-heading`.

### 5.2 버튼

| 종류 | 모양 | 예 |
|------|------|----|
| 주 버튼 | 배경 `--color-primary`, 흰 글자, 1px `--color-primary` 테두리, `--radius`. hover `--color-primary-strong` 배경 | [로그인] [가입] [만들기] [저장] [참석] [조회] [전송], 고른 채팅 탭 |
| 보조 버튼 | 흰 배경, 1px `--color-border`, `--color-text` 글자. hover 배경 `--color-bg-subtle` | [취소] [오늘] [로그아웃] [검색] [그룹 없이 참석] [참석 취소] [남기기] |
| 위험 버튼 | 흰 배경, 1px `--color-danger`, `--color-danger` 글자 | 행·카드 안 [삭제](날짜 상세, 회원 관리, 그룹 관리, 채팅 보관함) |
| 위험 채움 버튼 | 배경 `--color-danger`, 흰 글자, 1px `--color-danger` 테두리 | 확인 창의 [삭제](참석 취소 확인 포함). 이미지 내려받기 확인만 [내려받기]가 주 버튼이다 |
| 작은 버튼 | 보조·위험·주 버튼 모양 그대로, 높이 32px(모바일도), 글자 13px | 행·카드 안 [편집] [삭제] [보기], 채팅 탭 |
| 글자 버튼 | 배경·테두리 없음, `--color-primary` 글자 | 그룹 편집 패널의 [빼기], 데스크톱 날짜 상세의 `← 뒤로` |
| 흐린 버튼 | 배경·테두리 `--color-bg-muted`, 글자 `--color-text-faint`, `cursor: not-allowed`. 눌리고, 누르면 이유를 토스트로 알린다 | WF 2.3의 `{ 참석 }` `{ 그룹 없이 참석 }` `{ + 그룹 만들기 }` |
| 제출 중 | 원래 모양에 `opacity: 0.6`, 눌리지 않음(`:disabled`). 글자는 `저장 중…` `만드는 중…` `로그인 중…` `처리 중…` | 제출·확인 버튼, [전송] |

- 높이 `--control-h`, 좌우 안쪽 여백 `--space-3`, 글자 `--font-body`.
- ◀ ▶는 보조 버튼 모양의 정사각형(32×32, 모바일 44×44)으로 한다(이미지의 ◀ ▶ 버튼). 상단 바의 ≡·←, 모달 머리의 ✕·←, 서랍의 ✕는 같은 크기이되 테두리 없이 그린다.

### 5.3 세그먼트 선택

참고 이미지의 [일간|주간|월간|목록] 묶음 모양이다. 붙어 있는 보조 버튼들 중 고른 하나만 주 버튼 색으로 채운다. 두세 개 중 하나를 고르는 곳에 라디오 대신 쓴다.

- 쓰는 곳: SCR-05·WF-10 정원 `2명 단식 | 4명 복식/혼복`(SCR-04 그룹 없이 참석의 `기본` 모드 포함), SCR-06 상태 필터 `전체 | 참석가능 | 참석완료`, SCR-08 회원 편집 역할 `회원 | 관리자`.
- 고른 칸은 배경·테두리 `--color-primary`, 흰 글자. 키보드 포커스는 2px `--color-primary-strong` 바깥선.
- 안쪽은 `<input type="radio">`를 숨기고 `<label>`을 버튼처럼 그린다(키보드·폼 동작을 그대로 쓰기 위해서).

### 5.4 입력 칸

- 흰 배경, 1px `--color-border`, `--radius`, 높이 `--control-h`, 안쪽 여백 `--space-2`. 안내 문구 `--color-text-faint`.
- 포커스: 테두리 `--color-primary` + `outline: none`.
- 오류: 테두리 `--color-danger`, 칸 바로 아래 `--font-small` `--color-danger` 한 줄(WF 2.4 칸 오류).
- 잠김(WF 2.3 `(잠김)`): 배경 `--color-bg-subtle`, 글자 `--color-text-sub`, `readonly`.
- 체크 상자·라디오는 브라우저 기본을 쓰고 `accent-color: var(--color-primary)`만 준다. 날짜는 `<input type="date">`(L-16).
- 라벨: 데스크톱은 칸 왼쪽, 모바일은 칸 위(WF 2.1). `--font-body` `--color-text-sub`.

### 5.5 캘린더 칸 (WF-03)

참고 이미지의 월간 표 모양을 그대로 따른다.

- **요일 머리 행**: 배경 `--color-bg-subtle`, 높이 28px, 글자 `--font-small` `--color-text-muted`, 왼쪽 정렬, 안쪽 여백 `--space-2`. `일`은 `--color-sunday`, `토`는 `--color-saturday`.
- **날짜 칸**: 흰 배경, 오른쪽·아래 1px `--color-line`. 데스크톱 높이 96px·안쪽 여백 `--space-2`, 모바일 64px·`--space-1`(약 48px 폭, WF-03). 높이는 고정이고 넘치는 줄은 잘린다(`overflow: hidden`). 칸 전체가 눌리는 영역이고 hover 배경 `--color-bg-subtle`.
- **날짜 숫자**: 칸 왼쪽 위, `--font-small`, 평일 `--color-text`, 일요일 `--color-sunday`, 토요일 `--color-saturday`.
- **오늘**: 배경 `--color-bg-today` + 1px `--color-border-strong` 테두리(칸 안쪽으로 그려 크기가 변하지 않게 `box-shadow: inset 0 0 0 1px`).
- **✔(내가 참석한 날)**: 날짜 숫자 바로 옆(2px 띄움), `--color-primary` 700. 그룹이 많아 칸이 넘쳐도 가려지지 않는다.
- **그룹 `그룹명(n)`**: 숫자 아래에 그룹마다 한 줄, `--font-small` `--color-primary`, 줄 사이 2px. 칸 폭을 넘으면 말줄임(`text-overflow: ellipsis`). `●n` 표기는 쓰지 않는다.
- **범례**: 캘린더 아래 `--font-small` `--color-text-muted` 한 줄.
- 공휴일 표시는 하지 않는다(공휴일 데이터가 없다).

### 5.6 상태 배지 (R-5, WF 2.4)

| 상태 | 모양 |
|------|------|
| 참석가능 (n/정원) | 흰 배경, 1px `--color-success`, `--color-success` 글자 |
| 참석완료 (n/정원) | `--color-bg-muted` 채움, 테두리 없음, `--color-text-sub` 글자 |
| 참석불가 (n/정원) | 참석완료와 같은 모양. 지난 날짜에서 정원이 차지 않은 그룹(R-6) |

- `--radius-pill`, 높이 22px, 좌우 여백 `--space-2`, `--font-small`, 숫자는 tabular-nums.

### 5.7 목록·표·카드

- **날짜 상세 그룹 카드(WF-04)**: 데스크톱·모바일 모두 카드 하나에 그룹 하나. 1px `--color-line`, `--radius`, 안쪽 여백 `--space-4`, 카드 사이 `--space-3`. 첫 줄은 왼쪽 그룹 이름(`--font-heading`, 내 그룹이면 옆에 `--color-primary` ✔)과 오른쪽 상태 배지, 다음 줄은 참석자 이름(`--color-text-sub`), 아랫줄은 왼쪽 관리자 [편집]·[삭제](작은 버튼), 오른쪽 동작 버튼. 내가 참석한 그룹(`mine`)은 `--color-primary-weak` 배경 + 왼쪽 3px `--color-primary` 선(`box-shadow: inset 3px 0 0`)으로 표시한다.
- **표(데스크톱 SCR-06·SCR-08·SCR-09·SCR-10)**: 머리글 행 배경 `--color-bg-subtle`, 글자 `--color-text-sub` 700. 행 높이 40px 이상, 행 사이 1px `--color-line`. 누르는 행(SCR-06, SCR-10)만 hover 배경 `--color-bg-subtle`. SCR-10의 고른 행은 `--color-primary-weak` 배경. SCR-08의 삭제된 회원 행은 행 글자 전체를 `--color-text-muted`로 흐리게 한다.
- **카드(모바일)**: 표 한 행이 카드 하나가 된다(L-13, 같은 컴포넌트에서 CSS로 바꾼다). 모양은 그룹 카드와 같고(배경색 없음), 첫 줄 제목은 15px 700이다.
- **탈퇴 회원 표시**: `탈퇴 회원`, 관리자에게 보이는 `(탈퇴)`는 `--color-text-muted`로 쓴다(SCR 공통 요소).

### 5.8 모달·하단 시트·확인 창 (WF-05, WF-10, WF-11)

- 흰 바탕, 1px `--color-line`, `--radius`, 그림자 없음(SG-1). 뒤는 `--color-overlay`.
- 데스크톱 모달 폭 400px(회원 편집 패널 480px), 안쪽 여백 `--space-5`, 제목 `--font-heading`, 맨 아래 버튼 줄은 주 버튼 왼쪽·보조 버튼 오른쪽(WF 2.4).
- 모바일 하단 시트는 화면 아래에 붙고 위쪽 모서리만 `--radius`, 버튼 줄의 버튼은 폭을 나눠 채운다. 회원 편집 패널은 전체 화면이고, 머리 오른쪽 ✕ 대신 왼쪽 ←로 닫는다.
- 오른쪽 위 닫기 ✕는 테두리 없이 `--color-text-muted`, 누르는 영역 32×32(모바일 44×44).
- 확인 창(WF-11)은 모바일에서도 가운데 작은 창(폭 `min(400px, 100% - 32px)`), 버튼은 오른쪽에 모은다(앞 버튼은 위험 채움, 5.2).

### 5.9 토스트·안내 상자

- **토스트(WF 2.4)**: 배경 `--color-toast`, 흰 글자 `--font-body`, `--radius`, 안쪽 여백 `--space-3` `--space-4`. 화면 아래 가운데에서 `--space-6` 위, 3초 뒤 사라짐. 모바일은 좌우 16px 여백 전체 폭.
- **안내 상자**: 참고 이미지의 말풍선 모양 안내 상자는 만들지 않았다. SCR-07의 비밀번호 변경 안내는 토스트로 알린다.
- **노란 안내(`.notice`)**: 배경 `#fff6d6`, 글자 `#6b5200`(2.3), `--radius`, 안쪽 여백 `--space-2` `--space-3`. 강제 로그아웃 뒤 로그인 카드의 `! 다시 로그인해 주세요`에만 쓴다(WF-01).

### 5.10 빈 상태·로딩 (WF 2.4)

- 빈 상태: 목록 자리 가운데 `--color-text-muted` 글자만(위아래 `--space-6`). 다음 동작 버튼은 두지 않는다. 조회 오류 문구도 같은 모양으로 보인다.
- 로딩: 높이 16px, `--color-bg-muted` 줄 3개, 줄 사이 `--space-2`. 움직임(애니메이션)은 넣지 않는다.
- 앱 시작 시 로그인 복원 중에는 화면 가운데 `Badminatics` 글자만 `--font-title` `--color-text-muted`로 보여 준다.

### 5.11 그룹 채팅 (WF-12, WF-13)

- **탭**: 작은 버튼(5.2) 줄, 줄바꿈 허용, 사이 `--space-2`. 고른 탭은 주 버튼, 나머지는 보조 버튼.
- **대화 상자**: 1px `--color-line`, `--radius`. 메시지 목록은 높이 280px 고정 + 세로 스크롤, 안쪽 여백 `--space-4`, 메시지 사이 `--space-3`.
- **메시지**: 폭 최대 80%. 위 줄 `이름 · 시각`은 `--font-small` `--color-text-muted`. 말풍선은 `--color-bg-muted` 배경, `--radius`, 안쪽 여백 `--space-2` `--space-3`, 줄바꿈 유지. 내 메시지는 오른쪽 정렬 + `--color-primary-weak` 말풍선. 보관함(WF-13)은 모두 왼쪽, 같은 말풍선.
- **입력 줄**: 대화 상자 아래, 위쪽 1px `--color-line`, 안쪽 여백 `--space-3`. 입력 칸(5.4) + [전송](주 버튼).
- **붙여넣은 이미지 미리보기**: 입력 줄 위, 최대 120×120px, 1px `--color-line` + `--radius`, 오른쪽에 ✕ 아이콘 버튼.
- **채팅 이미지**: 말풍선 안 최대 240×240px, `--radius`, 커서 `zoom-in`. 불러오는 동안 120×80px `--color-bg-muted` 상자.
- **크게 보기**: 화면 전체를 `rgb(0 0 0 / 80%)`(2.3)로 덮고 가운데에 이미지를 화면에 맞춰 보인다. 커서 `zoom-out`, 오른쪽 위 ✕.

### 5.12 언어 선택

- `<select>` 하나, 입력 칸(5.4) 모양. 폭은 내용만큼, 높이 32px(모바일도), 좌우 안쪽 여백 `--space-1`.
- 상단 바 오른쪽(데스크톱은 로그인 정보와 [로그아웃] 사이), 로그인·가입 화면은 오른쪽 위(위 `--space-3`, 오른쪽 `--space-4`)에 둔다. 서랍에는 없다.
